# Word Combo Story Game

Pick a random silly adjective + noun combo (like "sparkly penguin"), describe what it is, and get a short, funny AI-written story about it.

## Run it

From the repo root:

```bash
pip install -r requirements.txt
python word-combo-story/game.py
```

Needs `ANTHROPIC_API_KEY` set in a `.env` file at the repo root.
